# magpie

> 一个 Spotlight 式启动器，找回你存过但忘掉的一切。

[English](README.md)

喜鹊爱收集闪亮的东西，又出了名地忘记藏在哪。人也一样：star 过再也没打开过的
GitHub 项目、埋在项目目录深处的文件、能描述出画面却怎么也找不到的截图。
**magpie** 是一个小巧的桌面启动器，把它们找回来——按下快捷键，输入模糊的印象
（或者直接拖进一张图），回车。

## 为什么选 magpie

**隐私优先，靠架构保证，不靠承诺。**

- **永不全盘扫描。** magpie 只索引你显式添加的文件夹——把常用的工作路径加进
  去即可，其余任何位置永远不会被读取。尊重 `.gitignore`（非 git 目录同样生
  效），跳过隐藏文件，绝不追踪符号链接越出你圈定的范围。
- **数据不出本机。** 索引是用户目录里的一个 SQLite 文件；嵌入模型通过 ONNX
  在本地运行，首次下载后完全离线可用。没有任何东西被上传。
- **索引内容完全透明**，任何文件夹一键移除，其文件、全文索引、向量一起清除。

**理解语义的搜索，不只是关键词。**

- 混合检索：SQLite FTS5（BM25）关键词 + 本地语义向量
  （`multilingual-e5-small`），RRF 排名融合。
- 跨语言：中文查询命中英文 README 和代码，反之亦然（100+ 语言）。
- 关键词命中显示高亮上下文片段（前后省略号），一眼看出为什么匹配。
- 毫秒级：向量常驻内存，查询嵌入约 5ms；模型预热期间关键词搜索照常可用。

## 数据源

### GitHub Stars

贴一个 PAT（无需任何 scope），magpie 同步你的完整 star 列表：名称、描述、
topics、README。自动检测取消 star，README 用 ETag 增量拉取，只有变化的内容
才重新嵌入。结果可按相关度 / 收藏时间 / 星数排序，每行显示最后 push 时间，
一眼识别弃坑项目。

### 本地文件

把日常工作目录加进来，按**全文**搜索：

- 80+ 种文本/代码格式，整文件读取（大小上限可配置，支持无上限）
- **PDF**：经 [pdf-inspector](https://github.com/firecrawl/pdf-inspector)
  解析（扫描版/乱码 PDF 仍可按文件名找到）
- **Word / Excel / PowerPoint**（docx、xlsx、pptx）
- 长文档自动分块（约 1600 字符、带重叠），每块独立向量——第 100 页里的一句
  话也能被搜到，文件按最佳块得分排名。

索引全程增量：启动时、手动刷新、以及常驻期间每 30 分钟自动跟进新增、修改和
删除的文件。

### 图片

文件夹里的每张图片都经 **SigLIP 2** 嵌入，按画面内容检索：

- **文字搜图**：输入"海边日落"（任何语言），匹配的照片带缩略图一起出现在结
  果里。
- **以图搜图**：把图片拖进窗口，或直接粘贴截图，magpie 找出最相似的已索引图
  片，并显示余弦相似度百分比。

## 使用

- 全局快捷键（默认 `Alt+Space`，可配置）唤出磨砂置顶浮窗；`Esc` 收起。窗口
  绝不自行消失——拖文件进来不会丢窗口。
- `↑↓` 选择 · `PgUp/PgDn` 翻页 · `Enter` 打开（repo 进浏览器，文件在资源管
  理器中定位）· `Tab` 切换数据源。
- 浅色/深色/跟随系统主题；索引进行时搜索框下有进度提示；托盘图标带快捷操作。
- 设置面板集中管理一切：GitHub token、索引文件夹、主题、快捷键、文件大小上限。

## 安装与构建

```sh
pnpm install
pnpm tauri dev      # 开发
pnpm tauri build    # 发布构建
cargo test -p magpie-core    # 核心测试
```

需要 Rust、Node + pnpm、WebView2/WebKit 运行时（Windows 11 与 macOS 自带）。
嵌入模型（共约 700MB）首次启动自动下载；预热期间关键词搜索立即可用。

## 架构

```
core/       Rust 库：SQLite + FTS5、GitHub 同步、目录索引、
            e5 + SigLIP 嵌入、混合排名——不依赖任何 UI
src-tauri/  Tauri 薄壳：命令、托盘、全局快捷键、窗口
src/        React 浮窗 UI（单窗口）
```

向量"数据库"刻意保持朴素：L2 归一化的 f32 BLOB 存 SQLite，内存暴力点积
（数万块 <15ms，100% 召回）。若语料规模超出，可在同一数据库文件上无缝换用
`sqlite-vec`。
